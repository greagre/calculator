Почему версии иногда выглядят не так, как были

Страницы у каждой версии свои, а вот скрипты — общие. Файлы b3-34-fix.js и b3-34-follow.js перезаписывались при выпуске новых версий, поэтому старая страница могла подтянуть уже изменённый скрипт. Отсюда и «в v6 вдруг учебный режим».

Как хранить версии дальше

Новое правило: выпустили версию — замораживаем её. Значит для неё создаются свои копии скриптов с номером в имени, например b3-34-fix-v3.js, и страница ссылается только на них. Старые файлы после этого не трогаются никогда.
  1. Новая версия — новый файл страницы: b3-34-v8.html.
  2. Её скрипты — копии с номером: b3-34-fix-v3.js.
  3. Старые файлы больше не редактируются — только читаются.
  4. Эта страница пополняется новой строкой сверху.
