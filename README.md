# Калькулятор

Мини-калькулятор на чистом HTML + JavaScript, без библиотек и сборки.

## Что умеет

- сложение, вычитание, умножение, деление;
- дробные числа;
- деление на ноль показывает «Ошибка»;
- кнопка **C** сбрасывает всё.

## Запуск

Просто открой `index.html` в браузере — или включи GitHub Pages:
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
Через минуту страница откроется по адресу `https://greagre.github.io/calculator/`.
